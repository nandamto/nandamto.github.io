# A mesa da Nanda ✧

**Site no ar:** [nandamto.github.io](https://nandamto.github.io)

Portfólio pessoal e guia de Lisboa do perfil [@nandamto](https://www.instagram.com/nandamto/), *turista onde mora*.

A página é uma mesa de trabalho vista de cima: uma base de corte verde-musgo com objetos espalhados. Cada objeto abre uma janela com uma parte do conteúdo.

| Objeto | O que abre |
|---|---|
| Caderno | Sobre mim |
| Polaroids | Lisboa em fotos |
| Bilhete de elétrico | Séries e formatos de conteúdo |
| Carta de tarô | Como funciona o veredito (aprovado, depende ou passo) |
| Postal | Ranking de bares favoritos |
| Cartão de visita | Contato |
| Grimório | Guia de Lisboa: 44 lugares com nota, carimbo, mapa de zonas e busca |
| Passaporte | 6 viagens com mapas ilustrados, paradas e feiras |

## Funcionalidades

- **Janelas arrastáveis** no computador; no celular, viram painéis que sobem do rodapé.
- **Guia de Lisboa filtrável** por tema (comer, Lisboa, por aí), por zona no mapa e por busca de texto.
- **Mapas de viagem desenhados com coordenadas reais**: latitude e longitude de cada parada são projetadas em SVG, com rios, parques, ruas, escala e norte. Os rótulos dos pontos se reposicionam sozinhos pra não ficarem uns por cima dos outros.
- **Links diretos** para cada janela e cada viagem (`#contato`, `#praga`, `#edimburgo`…).
- **Acessibilidade**: tudo funciona pelo teclado (Tab, Enter e Esc), os elementos têm rótulos para leitores de tela e as animações são desligadas para quem prefere menos movimento.

## Como foi feito

- HTML, CSS e JavaScript puros, **sem frameworks nem bibliotecas**.
- Um único arquivo `index.html`, com as fotos otimizadas e embutidas, sem dependências externas além das fontes.
- Tipografia: Newsreader, DM Mono, Reenie Beanie e Pirata One (Google Fonts).
- Hospedagem: GitHub Pages.
- Construído em parceria com IA (Claude, da Anthropic). A direção criativa, a identidade visual, a curadoria dos lugares e todas as opiniões são minhas; a IA ajudou a transformar isso em código.

## Privacidade

O código passou por uma revisão antes de ser publicado. Ele não contém dados pessoais, links privados nem metadados de localização nas fotos.

### English summary

*A mesa da Nanda* ("Nanda's desk") is a hand-crafted portfolio and Lisbon guide, built as an interactive desk where each object opens a window. It is plain HTML, CSS and JavaScript with no frameworks. It includes a filterable guide to 44 Lisbon places and illustrated travel maps drawn from real coordinates, and it works fully from the keyboard. It was built with AI assistance (Claude) under my creative direction, as part of my transition from advertising and content creation into tech.
